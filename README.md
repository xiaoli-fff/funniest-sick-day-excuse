One line to call in sick: my smartwatch says my heart rate hit 140 while I was asleep — either I'm very ill or it's finally learned to panic about Mondays like I do.

## Run it

```sh
node main.ts
```

The program writes the one line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
